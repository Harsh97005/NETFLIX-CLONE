# 🎬 Netflix Clone

A modern Netflix-inspired web application built using React and Firebase.  
It allows users to browse movies, view trailers, and authenticate using Firebase Auth.

---

## 🚀 Features

- 🔐 User Authentication (Login / Signup with Firebase)
- 🎥 Movie browsing using TMDB API
- ▶️ Trailer playback using YouTube embed
- 🧭 Protected routes with authentication
- 📱 Responsive UI (Netflix-like design)
- ⚡ Fast and modern React-based frontend

---

## 🛠️ Tech Stack

- React JS
- React Router DOM
- Firebase Authentication
- TMDB API
- CSS3
- Vite (or Create React App if used)
